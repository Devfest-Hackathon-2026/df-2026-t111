## 🎯 解決する社会課題

「伝統芸能に興味はあるけれど、敷居が高そう」「何から見ればいいか分からない」「難しそう」という若者の心理的ハードルを解消します。

本アプリは、**「① 診断 ➔ ② ミニ体験 ➔ ③ 詳細 ➔ ④ 行きたい」** の 4 つのスムーズなステップを通じて、誰でも気軽に自分の「推し伝統芸能」に出会い、本物の劇場へ足を運ぶ体験を創出します。

---

## 🌟 主要機能と画面フロー

```
① 適性診断 ───▶ ② AI ミニ体験 ───▶ ③ 詳細・おすすめ公演 ───▶ ④ 行きたいリスト
 (タップ式診断)   (見得・名乗り・三人遣い) (見どころナビ・立体カード) (Firestore・マップ)
```

### 1. ① 適性診断（Diagnosis）
- テンポの良いタップ式質問（7問）で、日本三大伝統芸能（能楽・人形浄瑠璃・歌舞伎）の中から、あなたの感性に最も響く芸能を判定・提案。
- 診断結果画面では、高画質・本物の舞台写真によるカルーセルと、魅力的な解説を紹介。
- 「詳しく見てみる」を押すと、該当芸能の詳細画面へダイレクトに遷移。

### 2. ② AI ミニ体験（Challenge）
- 👘 **歌舞伎「見得チャレンジ」**: カメラで自撮りした見得ポーズを、**Gemini 3.8 Flash** が画像認識でマルチモーダル解析！お手本画像の拡大表示機能付きで、迫力・表情・ポーズのキレを本格採点・講評。
- 🎭 **能楽「名乗りチャレンジ」**: プロのお手本動画を見ながら、マイクで「名乗り」のセリフを発声録音。**Gemini 3.8 Flash** が音声の抑揚・気迫・間合いをリアルタイムに音声講評。録音した自分の音声もすぐ確認可能。
- 🎎 **人形浄瑠璃「ひとり三人遣い」**: 人形浄瑠璃の醍醐味である「3人で1体の人形を操る」難しさと面白さを体感できる、タイミングタップ式音ゲー風ミニゲーム。師匠の講評つき。

### 3. ③ 詳細・おすすめ公演（Arts Detail）
- **見どころナビゲーション**: 気になるポイントをタップすると解説が広がるアコーディオン形式。
- **おすすめ公演スタックカード**:
  - 和風 2 行条件フィルター（地域・予算・日程・誰と）を選択すると、条件合致度をリアルタイム計算。
  - 本のようにめくれる立体スタックカード（「第一位」「第二位」…）で、初心者向けのおすすめ公演を直感的に発見。
  - Google マップの目的地ピン埋め込みやチケット購入ボタンを完備。
- **初心者の Q&A**: 初めての鑑賞の不安（服装・マナー・イヤホンガイド等）を解消。

### 4. ④ 行きたいリスト（Wishlist）
- 気になった公演を「♡」ボタンでワンタップ保存（Cloud Firestore リアルタイム同期）。
- 会場名を自動設定した **Google マップの道順案内（ルート検索）**、カレンダー追加、公式チケット購入ページへスムーズに接続。

## 🚀 活用した Google 技術

本プロダクトは、Google の最新クラウド技術と AI をフル活用して構築されています。

| 技術 | 活用内容 |
|---|---|
| **Gemini 3.8 Flash**<br>(Vertex AI / `@google/genai`) | 最新モデル `gemini-3.8-flash` を採用。サーバーサイド（Cloud Run）経由で、見得の写真（マルチモーダル画像解析）や名乗りの音声データをダイレクト解析。伝統芸能の型を正しく理解した初心者目線の温かい講評・アドバイスを生成。 |
| **Google Cloud Run**<br>(asia-northeast1) | Next.js 16（App Router）の standalone コンテナをサーバーレスで配信。迅速なスケーリングと高パフォーマンスなレスポンスを実現。 |
| **Cloud Firestore**<br>(asia-northeast1) | 匿名ログイン（Firebase Authentication）と連携し、ユーザー登録不要で即座に「行きたい」公演をクラウド保存・リアルタイム同期。 |
| **Google Maps Platform**<br>(JavaScript API & Maps URLs) | 全国の主要劇場（歌舞伎座、国立能楽堂、国立文楽劇場、南座等）をピン表示し、現在地からの距離ソートや、会場名付きルート案内リンクを提供。 |

## 💻 ローカル開発環境の起動

### 1. リポジトリのクローンと依存関係のインストール
```bash
git clone https://github.com/Devfest-Hackathon-2026/df-2026-t111.git
cd df-2026-t111
npm install
```

### 2. 環境変数の設定
`.env.example` をコピーして `.env.local` を作成し、必要なキーを設定してください。
```bash
cp .env.example .env.local
```

### 3. 開発サーバーの起動
```bash
npm run dev
```
ブラウザで [http://localhost:3000](http://localhost:3000) を開いて動作を確認できます。

### 4. 外部リンクの自動疎通検証
```bash
npm run check:links
```
アプリ内の全外部リンク（チケット購入・公式HP・動画等）が正常に接続可能かをワンコマンドで一括テストできます。
